A completed checklist is your observation—not distribution approval.

A review, not an automatic test

You decide which checks to perform. This page does not open TubeUnpack, install anything, connect accounts or run a test. Review the private-beta requirements before installing.

Fresh clean-Windows install/upgrade/uninstall, live Google login, Drive, captions and playback are still separate acceptance items. Do not perform destructive or account-changing checks merely to tick a box. Stop if the action or permission is not what you intended.

Optional, deliberate checks

For a requested clean-VM acceptance, record installation, upgrade/data retention, uninstall and no-system-Python conditions separately. These checkboxes alone cannot establish that gate.

Make feedback easy to act on

Use this pattern: Where I was → what I clicked → what I expected → what happened. Include Windows/browser versions and the visible error if useful. Say which checks were skipped or failed.

Do not enter tokens, passwords, configuration files, account names/email, private transcripts, whole data folders or unredacted logs. Review the generated file before sharing it.

Nothing is submitted. The download contains only checklist choices, the candidate version and the note you enter. Notes are not written to browser storage.

For a paper review, mark the checks you performed and write feedback separately. Do not include sensitive data.
