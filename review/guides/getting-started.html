Guide 01 / Your first session

A calm start.
Your first research feed.

TubeUnpack is a Windows application that opens its workspace in your browser. Start with your channels, then follow a question into a video, a transcript and saved research.

Before you start

You need a Windows 10 or 11 computer with a 64-bit processor, a browser, an internet connection and an invited Google test account to connect YouTube.

The installer includes Python. You do not need to install Python yourself, open a terminal or create a Google developer account.

This is a private candidate

Beta.13 is unsigned and has not been approved for unrestricted public download. Clean-Windows installation acceptance and owner review are still pending. Use it only as an invited tester, from the expected distributor. Windows may show an unknown-publisher or reputation warning; do not disable Windows protections.

Install, open, connect

  1. Choose where to install

    Run setup and choose a destination. Per-user installation is the default; installing for all users requires administrator approval. Desktop shortcut and Start TubeUnpack with Windows are optional and off by default.

    Starting with Windows runs the local server in the background. It does not open a browser or check for updates.

  2. Open TubeUnpack from Start

    Your browser opens the local workspace and welcome guide. A new profile starts blank. Choose Start setup, then Connect YouTube before importing subscriptions.

  3. Review the connection on Google's page

    The application registration is already included. TubeUnpack does not ask for your Google password. Choose the account—and channel or brand identity, if offered—that owns the subscriptions and playlists you want to use.

    Review the permissions: identity, email, YouTube read access and YouTube management access. This is not a read-only connection. Supported playlist and subscription changes still require actions you deliberately request.

  4. Return after approval

    Finish Google's consent flow and return to TubeUnpack. While the application is in Google's Testing mode, only invited accounts can sign in; reconnection may be needed after seven days.

    An unverified-app warning is not proof of public Google approval. If you are not invited or the app does not match the expected beta, choose Back to safety. Fresh live login and production verification remain separate acceptance checks.

Make the feed yours

Import deliberately

Open Import Subscriptions, review the channels and import your selection. Group them with categories that match the topics you follow. Importing adds local monitored sources; refreshing the feed does not change your subscriptions.

Follow one question

Open a video in the official YouTube player inside TubeUnpack. Read its description, inspect available captions and send it to the Analysis Desk when you want to investigate it. You can also paste a YouTube link into the top address bar.

Saved & Folders is local. YouTube playlist actions are separate. The optional Source Watch Later playlist is an ordinary private playlist created with your approval—not YouTube's built-in Watch Later.

Know what stays running

Closing the browser does not stop TubeUnpack's local server. Use the separate Stop TubeUnpack Start-menu shortcut when you want it stopped.

For an upgrade, save pending work first. The installer remembers the previous installation folder and keeps local data. Update checks can run when you open the app, but downloads and installation require approval; this candidate's public update delivery is not yet verified.

Uninstall through Windows Installed apps. Local research is kept by default. Interactive per-user uninstall asks twice before deleting it; silent or all-users uninstall keeps it. Uninstalling does not revoke access on Google's side.

If startup reports a port conflict, do not run multiple copies against it. TubeUnpack uses one local server per Windows session/port; report the visible error to your inviter.
