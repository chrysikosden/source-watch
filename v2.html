WRITTEN INSTRUCTIONS

Set up Source Watch

These steps are for invited beta testers. Use the Windows build and connection instructions provided with your invitation.

  1. Open the app

    Run the supplied Windows file. Source Watch opens its dashboard in your browser and displays the welcome guide on first launch.

  2. Connect YouTube and choose your sources

    Select Start setup, then Connect YouTube, and sign in on Google’s page. Review the requested permissions, choose the channels you want to follow and assign their categories.

    The current beta requests viewing and management access to YouTube. This is not a read-only connection.

  3. Find a video to examine

    Refresh the feed and narrow it by category, channel or search. Open Quick Brief for an initial overview extracted from the available transcript or metadata.

  4. Prepare and run the analysis

    Select Send to Analysis Desk, then Copy Deep + Transcript. Choose Open ChatGPT, paste and review the prepared text, and submit it. Follow up on the response and verify important claims against independent sources.

  5. Save the useful results

    Copy the response you want to keep into Save analysis result. Add notes and verification sources, then save the workspace in Saved research. Reopen it later or export it as Markdown.

Windows security notices

Use only the build supplied with your invitation. If Windows displays a security warning, verify the file and version with the beta organizer before proceeding. Do not disable Windows protection to run it.

Google sign-in and permissions

A private test build may display an unverified-app notice. Continue only if you are an invited tester, the app matches the expected Source Watch build, and you understand the requested access. If it is unfamiliar, choose the safe exit and ask the organizer.

Review the application name and every permission. The current workflow requests viewing and management access to YouTube, as well as account identity information. It is not a read-only connection. Management access enables supported account actions such as playlist updates or unsubscribing when you explicitly request them.

On a first connection, Google may show permission checkboxes: review and select the permissions required for the workflow before choosing Continue. A previously connected account may instead show an existing-access summary. Open the service details, review them, choose Done if shown, then Continue.

Return to Source Watch, verify the connected account, and wait for subscriptions to load. The video records an existing-access summary; it does not recreate first-time checkboxes.

PRIVACY

Your library is stored on your computer.

What is stored locally

Sources, video references, notes, cached transcripts and saved research are stored on your computer rather than in a separate Source Watch cloud account. Google authorization tokens are also stored locally.

What uses external services

Google and YouTube provide sign-in, account access and video data. You submit prepared text to ChatGPT yourself. Anything you send is processed under that service’s settings and policies.

Backups and synced folders

A local folder may still be copied by OneDrive or another sync service. Local storage does not, by itself, mean the data is encrypted. Protect your computer, authorization tokens and backups.

This website has no added analytics or account system. Loading the guide connects to YouTube. Hosting and external services may process connection information under their own policies.
